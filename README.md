# Зацепка: Поезда

3D-игра для Android (горизонтально), нативный OpenGL ES 3.0, без движков и без интернета во время игры.

## Что есть в прототипе

- Первое лицо: две модели рук появляются рядом с поездом.
- Левая половина экрана — левая рука, правая — правая. Тянете левый стик влево — левая рука хватается и **не отпускается**, пока не двигать стик вправо. С правой стороной наоборот.
- Оба стика вверх, когда обе руки заняты — забраться на крышу. На крыше под проводами бьёт током.
- Поезда: Сапсан 250, Ласточка 210, Метеор 400, Базовый 170 км/ч (в игре скорость уменьшена для геймплея, в HUD показывается «паспортная»).
- ТБшник видит вас на платформе → пишет в лог «вызвал охрану», затем «остановил поезд». Охрана бежит следом и ловит только если вы не едите на поезде.
- Станции, рельсы, шпалы, столбы, контактная сеть, деревья, туман, освещение.
- Лог событий сверху экрана, скорость, подсказки, экран задержания и рестарт по касанию.

## Управление

| Действие | Управление |
|---|---|
| Идти по платформе | левый стик |
| Поворачивать голову | правый стик |
| Зацепиться левой рукой | левый стик влево у поезда |
| Отпустить левую руку | левый стик вправо |
| Зацепиться правой рукой | правый стик вправо у поезда |
| Отпустить правую руку | правый стик влево |
| Залезть на крышу | оба стика вверх |
| Рестарт | тап по экрану после задержания |

## Сборка

APK собирается в GitHub Actions (`.github/workflows/build.yml`):

```sh
git push
# скачать artifact PoezdGame-apk с страницы Actions
```

Установка: включить «Неизвестные источники» и открыть APK.

> В реальности зацепка за поезда смертельно опасна. Это только игра.
